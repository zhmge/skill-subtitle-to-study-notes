# Subtitle to Study Notes

把讲解类视频的字幕文件整理成可供未观看者自学的 Markdown 笔记：概念顺序、结论卡、术语表、结构图，以及能跳回视频的时间戳链接。

> An agent skill that turns a lecture subtitle file into structured Markdown study notes for a reader who has not watched the video.

## 功能

- 读取 SRT、VTT、ASS/SSA、LRC 与纯文本，自动识别编码与格式
- 把碎片化的字幕行合并为保持原顺序的段落，输出编号转写稿与五组证据块
- 按说话人的概念顺序组织笔记，只允许把相邻概念合并成板块，不允许调整或拆散
- 结论卡只允许来自两个来源：说话人强调的内容、说话人给出的定义
- 识别并修正 ASR 术语误听，修正前需通过四道判定
- 时间戳转成 B 站跳转链接，板书内容按语音可支撑的程度重建，并标注为非原视频画面

## 依赖

- **Python 3**，仅用标准库
- 无需网络与凭据：解析与结构化全部在本地完成

## 快速开始

```bash
python "<skill 目录>/scripts/parse_subtitles.py" "<字幕文件>"
```

脚本输出编号转写稿与证据块；`--json` 给出同源结构化数据。分段判断有偏差时用 `--gap`、`--max-chars`、`--soft-min` 调参，不必另写解析器。

之后按 `SKILL.md` 的三步走：修术语（`references/asr-correction.md`）→ 写笔记（`references/note-format.md`）→ 过交付前检查清单。

## 产物

一份 `<视频标题>_学习笔记.md`，默认与输入字幕同目录。骨架包含：

| 区块 | 内容 |
|---|---|
| 学习地图 | 一段路线说明 + mermaid + 推荐阅读顺序 |
| 板块与概念 | `##` 为板块，`###` 为概念，每节带 `> **本节结论**：` 卡片 |
| 术语表 | 视频中出现并需要解释的术语 |
| 结构图 | 概念之间关系的 mermaid 图 |

## 反直觉之处

**字幕文件的块结构不是讲稿结构。** 一块字幕对应一段呼吸，不对应一个概念。直接按块写笔记，得到的是逐句复述；先合并成段落再定位概念边界，才会得到有层级的笔记。

**术语候选表只是证据，不是结论。** 脚本给出的近似词对不包含替换指令；漏掉的误听也不会出现在候选里。修正必须回到上下文判定，否则会把说话人真正说的词改错。

**压缩表达不等于压缩内容。** 填充语、重复、演算过程可以删；例子、因果链、对比、反例不能删——删掉它们，笔记就不再能替代观看。

## 已知限制

- 输入必须是已完成的字幕文件；不接受实时转写与直播流。
- 视觉为主的讲解（几何证明、纯图示）语音撑不起重建，笔记会只剩骨架，此时应直接说明而不产出。
- 单说话人假设。多人讨论、插播广告会把板块顺序打乱，只做标记而不自动修正。
- 术语修正的准确率取决于字幕质量；字幕严重错位或混语时输出会不可用。
- 跳转链接依赖字幕里能识别出 B 站 BV/av 号，且需人工确认该 id 确属本视频。

├── README.md                       本文件
├── LICENSE                         MIT
├── references/
│   ├── asr-correction.md           误听类型、四道判定、修正边界
